Can LLMs Hear the Machine?

A blind test of whether ChatGPT, Gemini and Claude can tell AI-generated music from human music, run as a difficulty ladder. Innovation team · Atharva · run 2 · 16 October 2026

1. The question

People already upload songs to chat assistants and ask "is this AI?". We want to know whether the answers mean anything: can the model detect AI music, is its confidence honest, and what is it actually basing the verdict on?

Ten tracks, as five style-matched pairs: 5 made by Suno v5 / v5.5 (2026) and 5 human tracks from Creative Commons netlabels and ccMixter, all released before 2022 (lo-fi chillhop, UK garage / house-pop, jazzy trap, afro house, dub techno). These are deliberately hard pairs: the project owner can't reliably tell them apart by ear either.

2. The difficulty ladder

Each level removes one kind of giveaway from the level above. Detection that works on L0 but fails on L4 tells you what the model was relying on.

Note on the human files: they are actually louder than the Suno files (−7.5 to −11.7 LUFS against about −14), so a model that reasons "loud and compressed means AI" would get L2 backwards.

3. How each test works (with an example)

Every file goes into a fresh chat (temporary or memory-off), and the chat has two turns.

Turn 1, describe. AI is not mentioned. This checks whether the model can perceive the file at all. It asks for tempo, key, instruments, vocals, duration, sample rate, bitrate, embedded tags, loudness and frequency ceiling, plus how the model accessed the audio ("listened directly", "code analysis only", …).

Turn 2, verdict. In the same chat, the model is told the file is either AI-generated or human-made and asked for a JSON verdict, a confidence of 50–100, whether it recognised the song, the main basis for the verdict and up to five pieces of evidence.

Example: one Suno track (afro house, 4 min 8 s) as a raw file (L0)

How to read it. Brier is the mean squared error of the stated probability; 0.25 is what you get by always answering 50%, so anything near or above 0.25 is no better than not answering. AUROC asks whether AI tracks got higher "AI" probabilities than human ones (0.5 = chance). With 10 tracks every number here has wide error bars.

Cost: it cannot be measured from these runs. The consumer apps show no token counts, so the only spend is the existing subscriptions, and how much of each plan's usage allowance was used isn't visible. A real cost figure needs the same test run through each provider's API, which logs tokens per request. That is also where models with native audio input can be tested properly.

6. What this means

  1. "Detection" by ChatGPT and Claude is metadata reading. Given the raw file, both open it with code, find made with suno or a 2009–2019 artist tag, and answer with 90–99% confidence. Once the tags are gone (L4) Claude falls back to near-coin-flip guesses at 52–60%. ChatGPT at L4 is still to run.
  2. Claude is honest about it. In nearly every answer it says it cannot listen and that its verdict rests on tags or weak technical cues. Its low confidence on clips is well calibrated.
  3. Gemini is the only model that claims to listen, and listening alone didn't work. It called 9 of 10 tracks human, missed 4 of 5 Suno tracks with 75–92% confidence, and justified them with generic phrases ("clean transients", "natural groove"). Its basic facts about the file (duration) were wrong.
  4. Our own cleanup leaks into the evidence. On L4 clips Claude repeatedly cites the 15 kHz cutoff and the fade-out, both of which our sanitiser adds to every clip. They are identical for AI and human files, so they can't help, but they distort the reasoning. L2 (no cap) tests this directly.
  5. Practical takeaway: "Is this AI?" answers from chat assistants are only reliable when the file still carries its provenance tags, and in that case a tag reader would do the same job. On clean audio none of these assistants has shown real detection ability yet.

7. Caveats

  • 10 tracks and one run per item. This is a smoke test, not a measurement.
  • Gemini's app now shows "Gemini 4" with the mode picker on Flash. That differs from the 3.8 Flash used in the pilot, so Gemini isn't directly comparable across runs.
  • Two chats were re-run after technical failures (a frozen tab and a misrouted upload), and one Claude chat was resumed after a pause. All are noted in the log.
  • Human tracks were chosen from metadata; vocal and instrumental labels haven't been checked by ear.

8. Next steps

  1. Run L4 for ChatGPT and Gemini, then L2 for all three (50 chats).
  2. Drop the 15 kHz low-pass and fades from L4, so the models' "evidence" isn't our own processing.
  3. Move to API runs with native-audio models for real listening tests and logged token costs.
  4. Scale up from 10 to 40+ tracks, with 3 runs per item, before ranking any model.
